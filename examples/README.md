# Examples

## BETSI round-robin reference isotherms

`betsi_HKUST-1.csv` and `betsi_Zeolite-13X.csv` are N₂ (77 K) adsorption
isotherms from the BETSI round-robin study. Each file is a plain two-column
CSV — `relative pressure, quantity adsorbed (cm3/g STP)` — with one header row
(no BJH table, no desorption branch, no instrument summary).

| File | Material | Published BETSI optimal BET area (m²/g) |
|---|---|---|
| `betsi_HKUST-1.csv` | HKUST-1 (Cu₃(BTC)₂ MOF) | 1556 |
| `betsi_Zeolite-13X.csv` | Zeolite 13X | 833 |

- **Source:** Osterrieth, J. W. M. et al., *Adv. Mater.* **2022**, *34*, 2201502,
  DOI 10.1002/adma.202201502.
- **Licence:** CC BY (the BETSI reference data are distributed under a Creative
  Commons Attribution licence).
- **Origin:** downloaded from <https://github.com/fairen-group/betsi-gui>.

These are the two files used by `tests/test_betsi_reference.py` as a regression
check: the Rouquerol-consistent BET surface area computed by `rouquerol.py`
must agree with the published BETSI value to within 2%.

The remaining file in this directory, `reference_mesoporous.xlsx`, is the
synthetic, self-consistent Type IV reference generated by
`make_reference_data.py` (see the main README).
